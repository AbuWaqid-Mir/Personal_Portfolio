# Personal Portfolio (Website)

### Overview
A professional personal portfolio website built from scratch using HTML, CSS and JavaScript.  
Created to showcase my programming skills, projects and experience as an aspiring Software Engineer.  
Includes multiple pages to introduce myself, display my projects and skills, and to provide access to my GitHub profile.  
The website has been published online using GitHub pages, allowing others to view my portfolio through a live website (https://abuwaqid-mir.github.io/Personal_Portfolio/index.html)

### Features
- Multi-page Website
- Navigation Bar
- Projects Showcase Page
- Skills Page (Technical and Personal)
- Link to GitHub Profile
- Dark/Light Mode
- Responsive Design (website works on different screen sizes, including desktop and mobile devices)

### Skills Demonstrated:
- HTML page structure
- CSS styling & layout
- Responsive web design
- JavaScript DOM manipulation
- Event Handling
- Use of localStorage (in JavaScript)
- Reusable CSS classes
- Problem Solving & Debugging

### Technologies Used
- PyCharm
- HTML
- CSS
- JavaScript

- GitHub Pages

### How To Run
1. View Online: (https://abuwaqid-mir.github.io/Personal_Portfolio/index.html)
2. Run Locally:
- Clone the repository
- Open the project folder
- Open "index.html" in a web browser
