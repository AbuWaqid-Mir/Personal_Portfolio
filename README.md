# Personal Portfolio (Website)

### Overview
A professional personal portfolio website built from scratch using HTML, CSS and JavaScript.  
Created to showcase my programming skills, projects and experience as an aspiring Software Engineer.  
The website includes multiple pages to introduce myself, display my projects and skills, and provide links to my professional profiles.  
The website has been published online using GitHub Pages, allowing others to view my portfolio through a live website.

**Live Website:** https://abuwaqid-mir.github.io/Personal_Portfolio/index.html

### Features
- Multi-page Website
- Navigation Bar
- Projects Showcase Page
- Skills Page (Technical and Personal)
- Contact Me Page
- Links to GitHub and LinkedIn profiles
- Dark/Light Mode
- Dark/Light Mode preference saved using localStorage
- Interactive hover effects
- Responsive Design (website works on different screen sizes, including desktop and mobile devices)
